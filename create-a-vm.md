# Create a VM lab
The VM is running the Ubuntu Linux OS 24.04.2  
After spinning up the VM the first time I got a crazy error code that I consulted google about. There were a ton of different responses to the same error code on Virtual Box forums and other sites, so I tried the one thing that was in the dialogue box of the error itself which was rebooting my system. This worked and I could proceed with the Ubuntu installation after that no problems.  
I allocated 4GB of RAM to the VM as that was the on the higher end of the recommened amount and my system has plenty to spare. Same with the hard disk space, I allocated 32GB.  
If I allocated too much RAM to the VM there was a possibility the my host system could have suffered performances decreases as it wouldn't have enough to keep doing everything else it's doing in *addition* to running the VM.
## Your first VM
I enabled 3D acceleration and allocated more video memory to the VM. This is because the VM had very little video memory provisioned to it by the host computer by default so the video/graphical performance was poor.  
Animations were much smoother after the changes.
Making sure the VM has enough hardware power (from the host CPU or RAM), and ensuring you allocate enough disk space for the VM to use.
